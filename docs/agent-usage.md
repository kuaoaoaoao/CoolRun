# CoolRun Agent 使用说明

> 面向使用者，不是设计文档。设计见 `agent-engine-design.md`。

## 1. 怎么叫出它

| 方式 | 操作 |
| --- | --- |
| 全局快捷键 | `⌥⌘A`，任何 app 里都能用 |
| 菜单栏 | 点鲸鱼图标 → 切到「AI 助手」 |
| 桌宠 | 双击桌面上的鲸鱼娘 |
| 快捷指令 | 在输入框里敲 `/` |

面板是同一个 popover，切到别的模块再回来，对话还在。

## 2. 第一次用

打开面板 → 右上角齿轮 → 选协议、填 Base URL、模型名、API Key。

四种协议都支持：

- **Chat** — OpenAI `/v1/chat/completions`，兼容面最广（DeepSeek、Kimi、Qwen、各类中转网关都走这个）
- **Responses** — OpenAI 新的 `/v1/responses`
- **Claude** — Anthropic `/v1/messages`
- **Ollama** — 本地模型，默认 `http://127.0.0.1:11434`

本地模型不用联网也不用 key，只要 Ollama 跑起来、模型拉下来就行。注意小模型（0.5B 那种）经常不会正确地调工具，7B 以上才稳。

「从 AI 助手同步配置」可以把之前助手模块里填过的配置直接搬过来。

## 3. 能做什么

### 场景卡

空对话时有 12 张卡，点一下就开始：

电脑体检 / 金价快报 / 今天有什么 / 谁在吃内存 / 电池还行吗 / 能清理什么 / 记一笔 / 剪贴板找东西 / 提醒我 / 额度还剩多少 / 截个图 / 切到金价

需要补充信息的卡（比如「记一笔」）点了之后会把提示语填进输入框，不会直接发出去。

### 斜杠指令

```
/体检  /金价  /今天  /内存  /电池  /清理  /记 <内容>  /剪贴板 <词>
/提醒 30m 喝水   /额度  /截图  /切金价
/tool system_snapshot       直接跑一个工具
/help                       看全部
/clear                      清空对话
```

### 工具浏览器

状态栏的九宫格按钮 → 看到当前允许的所有工具，按权限分组。选一个，表单会自动根据 JSON Schema 生成，填完点运行就能直接调 —— 不用经过模型，适合「我就想看一眼某个数据」的场景。

L2 及以上的工具点一次变「确认执行」，再点一次才真的写。

### 对话里能干什么

工具调用会显示成卡片（图标 + 工具名 + 参数），点开看返回的原始结果。

L2 工具（写笔记、建提醒、截图）执行前会弹一条橙色的确认条，90 秒不点自动拒绝。

每条消息右键可以复制或删除。历史会存下来，重开 app 还在，最多 200 条。

## 4. 权限

设置里可以选工具等级，模型能看到的工具集永远不超过这个等级：

| 等级 | 含义 | 例子 |
| --- | --- | --- |
| L0 只读 | 看，不改任何东西 | 系统快照、金价、搜笔记 |
| L1 可逆 | 改了能马上改回来 | 切面板、发通知、写剪贴板 |
| L2 持久 | 会留下痕迹 | 建笔记、建提醒、截图 |
| L3 危险 | 执行命令、写文件 | 默认不注册 |

默认是 L0。想让 agent 帮你记东西，调到 L2。

## 5. 插件

插件是本地目录，后缀 `.coolplugin`：

```
我的插件.coolplugin/
├── manifest.json
└── main.js
```

`manifest.json`：

```json
{
  "id": "com.example.hello",
  "name": "Hello",
  "version": "1.0.0",
  "summary": "一个示例插件",
  "author": "你",
  "main": "main.js",
  "permissions": ["storage", "notify"],
  "tools": [
    {
      "name": "now",
      "summary": "返回当前时间",
      "handler": "now",
      "parameters": { "type": "object", "properties": {} }
    }
  ]
}
```

`main.js`：

```js
function now() {
  var n = (coolrun.storage.get("count") || 0) + 1;
  coolrun.storage.set("count", n);
  return "现在是 " + new Date().toLocaleString() + "（第 " + n + " 次）";
}
```

能用的 API：`coolrun.log` / `coolrun.storage.get|set` / `coolrun.httpGet` / `coolrun.notify` / `coolrun.copy`，每个都要在 `permissions` 里声明。

装：设置 → 插件 → 安装，选那个目录。装完工具会自动出现在工具浏览器里，也能被模型调用。

## 6. 桌宠

桌面右下角那只鲸鱼。

- 点一下：逗她一下，她会蹦一下并回你一句
- 双击：打开 Agent
- 点气泡：也打开 Agent（气泡比身体更像「有话要说」）
- 拖动：按住拖到任意位置，位置会记住
- **甩出去**：松手时如果还在动，她会像抛出去一样飞、撞墙弹两下、落地滑一段再停
- 右键：打开 Agent / 跟她说句话 / 让她睡会儿 / 大小 / 隐藏

### 她会看你干活

气泡不是随机说的，跟着 Agent 的进度走：

| 状态 | 气泡 | 动作 |
| --- | --- | --- |
| 空闲 | （不说） | 呼吸、摇摆，每 16~34 秒自己做个小动作 |
| 思考中 | 本鱼在想… | 晃得比平时快 |
| 在调工具 | 在用「查金价」 | 工具名翻成人话，气泡随工具切换 |
| 等你确认 | 等你点一下下～ | 晃得最急，幅度最大 |
| 完成了 | 想好啦！ | 停 2.6 秒再回空闲 |
| 出错了 | 哎呀，卡住了 | 歪向一边，停 4 秒 |
| 睡着了 | z Z | 4 分钟没人理她就睡，点一下叫醒 |

### 手感是怎么做的

拖拽不是「窗口跟着鼠标走」这么简单：

- 拖的时候记最近 140ms 的位移样本，松手时用它们估速度（像素/秒，上限 2600）
- 速度超过 60 就进入物理模式，交给 `PetPhysics` 逐帧积分
- 参数照桌面宠物的通用手感：重力 1400 px/s²、撞墙恢复系数 0.78、
  落地摩擦 2.5/s、空气阻力 0.2/s、低于 100 px/s 就不弹了
- 落地按冲击力压扁（横向 1.16 倍、纵向 0.86 倍，0.42 秒内弹回），
  冲击超过 700 还会触发一次触控板震动
- 边界取宠物所在的那块屏的 `visibleFrame`，所以能跨屏飞，也不会飞到 Dock 底下

这些动效全部「记时间戳 + 按当前时刻算」，没有一处 `withAnimation`。
原因是渲染层是 `TimelineView` 逐帧重算的，隐式动画在那儿不会插值；
按时钟算反而更稳，掉帧也只是跳一下。

物理那层是纯值类型（`PetPhysics.swift`），不碰窗口，所以能单测：
`CoolRunTests/PetPhysicsTests.swift` 覆盖重力、反弹、摩擦、边界、静止。

### 她是怎么画出来的

用的是角色立绘（`CoolRun/Assets.xcassets/PetWhale.imageset/pet-whale.png`），
动效全部由 SwiftUI 合成：呼吸（纵向 0.994↔1.012 拉伸，锚点在脚底）、摇摆
（±1.5°）、地面影子（跟着呼吸缩放）、悬停放大 4%、思考时冒气泡。

没有用 Live2D，原因很实际：Live2D 要 `.moc3` 模型 + 贴图 + 物理参数，从一张
PNG 手工绑骨骼是几天的工作量，而 Q 版立绘的呼吸摇摆已经有「活着」的感觉。
BongoCat 那种 Rust + Live2D 的方案可以借鉴渲染层，但要先有模型文件。

换角色很简单：把新的 PNG 抠图（透明背景）覆盖 `pet-whale.png`，尺寸比例保持
约 355×393 即可，代码不用动。抠图用 macOS 自带的 Vision：

```swift
let request = VNGenerateForegroundInstanceMaskRequest()
```

### 想要更进一步的动画

如果以后有了 Live2D 模型，或者拿到了同一角色的多张表情/动作图，可以：

1. 多张表情图 → 按状态切换（思考/说话/睡觉），`WhalePetView` 里换 `Image` 即可
2. 序列帧 → 把 PNG 序列放进 imageset，用 `TimelineView` 逐帧播放
3. Live2D → 引入 Cubism SDK，工作量约一周

现在的方案是「一张图 + 合成动效」，性价比最高的一档。

## 7. 两个版本

| | Lite | Full |
| --- | --- | --- |
| 体积 | 8.6 MB | 107 MB |
| 原生引擎 | ✅ | ✅ |
| 云端 / 本地 LLM | ✅ | ✅ |
| 工具 / 插件 / 桌宠 | ✅ | ✅ |
| DSH 引擎 | 首次使用时下载（约 90 MB） | 内置，离线可用 |

功能完全一样，区别只在 DSH 引擎是内置还是按需下载。

## 8. 引擎怎么选

设置 → 引擎：

- **原生引擎**（默认）：Swift 实现，四种协议 + 工具循环，体积为零，够用
- **DeepSeek Harness**：能力更全（多步任务、子代理、skill），代价是 300 MB 和一个外部进程

两个引擎用的是同一套工具、同一套权限闸门，切换对使用者是透明的。

## 9. 出问题了

- **一直弹钥匙串授权**：已经在 v4.3 改成 AES-GCM 本地加密文件，不再用钥匙串。如果你还看到弹窗，说明跑的是旧包。
- **模型不调工具，只输出 JSON 文本**：模型太弱，换 7B 以上的。
- **DSH 引擎起不来**：设置里看运行时状态；缺的话点下载。日志在 `~/Library/Application Support/CoolRun/agent-home/`。
- **快捷键没反应**：可能被别的 app 占了，换一个或者用菜单栏图标。

### 金价分析

空面板里有「现在能买吗」「我的持仓」两张卡，也可以直接问：

- 现在适合买黄金吗
- 金价这周会怎么走
- 我手里 20 克成本 820，要不要卖

Agent 会先调 `gold_technical` / `gold_forecast` / `gold_strategy` 拿真实数据，
再给结论、依据、风险和具体操作。所有回答都基于历史统计与规则模型，
不构成投资建议。


## 每日简报

Today 面板顶部有一张简报卡，把当天最值得知道的三四件事压成几行：

- 系统只在你真有问题时占一行（磁盘、内存、CPU），平时不出现
- 金价带涨跌，平盘时只写「平盘」，不糊你一脸 `+0.00`
- 最近一个倒计时或生日
- 英语还差几个
- AI 额度低于 20% 才提醒

点任意一行跳到对应模块。「让本鱼说说」会把这几行交给模型，改写成两三句人话；
没配模型或者离线也能用，简报本身是本地算出来的。

提醒时间在「设置 → 通用 → 每日简报」里改，默认每天 8:30 推一条通知。

## 后台体检

CoolRun 每隔 6 小时自己看一眼机器，只有真有问题才出声：

| 检查 | 什么时候说话 |
| --- | --- |
| 磁盘 | 已用 ≥ 88%（≥95% 升级为严重） |
| 内存 | 已用 ≥ 92% |
| 睡眠 | `pmset` 显示合盖掉电 ≥5%、或有进程拦着不让睡 |
| 网络 | 网关/DNS/丢包任意一项不过 |

同一天最多推一条通知，避免反复打扰。有结论时，Today 面板的简报第一行会多一条
「磁盘不太够了 → 去看看」，点进去就是诊断页。

开关在「设置 → 通用 → 后台体检」，里面还有「现在检查」按钮和上次检查时间。
想让它永远闭嘴，关掉这个开关就行。

## 磁盘清理

诊断页的第一个分区就是「清理」。它回答的不是「用了多少」，而是「**哪几样能删**」：

```
53.87 GB 可以释放
● 可以放心清
  ✓ 应用缓存      22.58 GB   删掉后第一次打开会稍慢，之后自己重建
  ✓ npm 缓存       9.94 GB   删掉后装依赖会重新下载，已装好的项目不受影响
  ✓ pnpm 存储      5.94 GB   已有 node_modules 仍可用
  ✓ Xcode 编译缓存  2.85 GB   下次编译从头来，慢一点但不会出错
  ✓ 运行日志        436 MB   删掉不影响功能
○ 删了不可恢复
  ○ 废纸篓、iPhone 本地备份 —— 这些默认不勾
○ 占地方的大文件（>300 MB，来自下载/桌面/文稿/影片）
```

- 安全的默认勾上，不可恢复的默认不勾——你只需要看一眼、点「清理」。
- 一律走**废纸篓**，不是直接删。反悔了还能捡回来。
- 每一项都写了「删了会怎样」，不写「建议删除」这种空话。
- 大文件只列出来、不替你决定，因为那是你的东西。

## 剪贴板

剪贴板以前只是「能翻到就行」，现在多了三件事，都不需要你记住什么命令。

### 按类型过滤

历史超过 6 条时，搜索框下面会出现一排分类胶囊：

```
全部 42   链接 9   命令 6   代码 5   数字 4   长文 3
```

分类是**本地算的**——看开头像不像 `git`、有没有 `://`、是不是成对的括号、
是不是只有数字和符号。所以它不联网、不花钱、内容一个字节都不会离开这台 Mac。

判定顺序是有讲究的：先认链接，再认命令，然后代码、纯数字、长文，最后才是普通文字。
反过来会被误判——链接里的 `://` 很像代码，代码里的数字也不该当数字看。

分类结果会缓存到历史变化为止，不在每次界面刷新时重算。这一条是修 bug 修出来的：
早先版本把分类写在界面刷新路径里，200 条历史 × 6 个胶囊 = 每次刷新上千次字符串搜索，
点一下剪贴板就能把 CPU 打到 62%、界面直接卡住。现在一次算完、存起来，
`ClipClassifierPerformanceTests` 盯着这个指标（4000 次判定必须远低于 0.5 秒）。

### 让本鱼整理

每条记录右下角有一个 ✨（太短的记录不显示，整理八个字没有意义）。
点开是四个动作：

| 动作 | 干什么 | 适合 |
| --- | --- | --- |
| 精简成要点 | 压到 5 条以内，保留数字、时间、金额 | 长会议记录、公告 |
| 清理格式 | 去空行、行号、页眉页脚、转载声明，把断掉的句子接回去 | 从网页/PDF 复制的东西 |
| 提取待办 | 抽出「谁要做什么、什么时候」 | 聊天记录、需求文档 |
| 翻译 | 中文→英文，其他→中文 | 英文邮件、日文说明 |

结果直接出现在列表上方，可以「复制」，也可以「存成笔记」——
存的时候自动放进一个叫「剪贴板整理」的分组，不跟你原来的笔记混在一起。

超长的内容只送前 6000 字进去，结果里会写明「只看了前 6000 字」，
不让你以为模型读完了整篇。

### 按意思找

关键词搜不到时，空状态里会出现「让本鱼按意思找找」。

比如你复制过一串 `postgres://...`，现在想找它，但只记得「那个存分析数据的库」——
模糊搜索匹配不到，语义搜索可以。做法是把最多 40 条候选编号喂给模型，
让它只回一个编号数组（`[3,7]`），这样回答短、便宜、也好校验。

命中的条目前面会有一条横幅写着「按意思找到 N 条」，点「清除」回到普通列表。

注意：这条路径**会把候选片段发给模型**。如果剪贴板里有密码、令牌，
要么先关掉记录（面板右上角的暂停键），要么别用这个功能——分类过滤和关键词搜索
永远是本地的。

## 耗电

菜单栏软件最怕「看不见却一直在跑」。这一版把待机功耗当指标测过一遍，
方法是看进程累计 CPU 时间（`ps -o cputime= -p <pid>` 取 60 秒增量），
而不是 `top` 那个会跳来跳去的百分比。

| 状态 | 待机 CPU |
| --- | --- |
| 全部优化前 | 5.9% |
| 系统采样分轻重两档 | 4.8% |
| 再关掉桌宠动效 | 2.0% |
| 关掉桌宠 | 1.9% |

做了三件事：

- **系统采样分档**。面板关着的时候只采 CPU / 内存 / 电池 / 网络，跳过磁盘和温度传感器——
  磁盘那项要问系统「重要用途可用空间」，会连带触发 CacheDelete 和 APFS 卷角色枚举，
  是整轮采样里最贵的一步。点开面板的瞬间再切到全量，并立刻补采一次，所以看不到空数据。
- **剪贴板分类不再在界面里现算**。以前每次界面刷新都重新给 200 条记录分类，
  点一下剪贴板能把 CPU 顶到 62%（系统会因此生成 `cpu_resource` 诊断报告）。
  现在分类结果缓存成一张表，只在历史变动时重算一次，200 条分类耗时 0.27 秒，
  界面上只是查表。
- **桌宠给了省电动效开关**。待机动效实测占 2.5% 左右，而且和帧率、模糊关系都不大——
  12fps 降到 6fps、去掉投影模糊，数字几乎不动，说明成本来自「窗口每秒重绘」这件事本身。
  与其硬压帧率，不如把选择权交出去：设置 → 通用 → 桌宠 → 播放动效，关掉画面定格，
  点击、拖动、甩出去、气泡提示都照常。

剩下的 1.9% 是基线：每秒一次系统采样、剪贴板 0.8 秒一次的轮询、
菜单栏金币图标的动画定时器。想再往下压就得动这些的采样节奏，
代价是数据变迟钝，暂时没做。
