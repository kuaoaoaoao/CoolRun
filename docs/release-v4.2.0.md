# v4.2.0 面板模块自定义显隐

CoolRun 是一个本地优先的 macOS 菜单栏工作台。本次更新让你自己决定面板上显示哪些功能。

## 本次更新

### 面板模块显隐控制

- 新增 **设置 → 通用 → 面板模块**：9 个功能模块（今天、监控、金价、日历、英语、Codex、备忘录、剪切板、诊断）均可独立开关。
- 默认只显示 **监控、金价、日历、剪切板** 四个模块，其余按需开启，导航栏更清爽。
- 至少保留一个模块可见，最后一个模块的开关会被锁定，导航栏不会变空。
- 关闭当前正在查看的模块时，自动切换到第一个可见模块，重启后也会落到可见模块。

### 数据与备份

- 显隐配置本地持久化，并随「数据 → 备份与迁移」一同导出、导入，换机不丢配置。

## 升级说明

- 升级后导航栏将按新默认值只显示 4 个模块，其余模块在设置中一键开启即可，数据不受影响。
- 被隐藏模块的快捷键（⌘0~⌘8）会随按钮一起停用。
- 快捷指令、菜单栏右键菜单等入口仍可直达被隐藏的模块。

## 隐私边界

- 本次更新不涉及任何网络请求与数据上传，显隐配置仅保存在本机。
- 匿名统计保持默认关闭。

## 验证

- macOS Debug 全量构建通过（Xcode 17，macOS 15.0+）。
