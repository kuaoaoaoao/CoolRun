# 2026-10-16

## 面板 Tab 显隐控制功能

为 CoolRun 菜单栏面板新增「模块显隐」功能：

- `ContentView.swift`：`ViewMode` 增加 `defaultVisible`（monitor/gold/calendar/clipboard）；`ModuleNavigationRail` 改为渲染 `settings.visibleViewModes`；`ContentView` 初始 tab 用 `AppSettings.initialViewMode` 兜底，并监听 `visibleTabRaws` 变化自动切换。
- `AppSettings.swift`：新增 `@Published visibleTabRaws: Set<String>`（UserDefaults key `visible_tabs`，存排序数组）；辅助方法 `visibleViewModes` / `isTabVisible` / `setTabVisible`（保底至少一个可见）/ `initialViewMode`；新增多语言文案 `panel_tabs` / `panel_tabs_desc`。
- `MenuBarMonitorView.swift`：与 ContentView 相同的初始兜底与自动切换逻辑。
- `SettingsView.swift`：通用页新增「面板模块」卡片，9 个 tab 各一个开关，最后一个可见模块禁止关闭。

注意：首次运行（无 `visible_tabs` 持久化值）默认只显示监控/金价/日历/剪切板。用户确认**不做老用户迁移**，升级后统一按新默认值。

## 代码审计（同日）

审计上述改动后修复：

- `AppSettings` init：读取 `visible_tabs` 时用 `ViewMode.allCases` 过滤失效 raw，全失效回退默认（防导航栏为空）。
- `setTabVisible` / SettingsView disabled：保底计数改用 `visibleViewModes.count`（过滤后）而非 `visibleTabRaws.count`。
- `DataMigrationManager`：`SettingsData` 新增可选字段 `visibleTabs`（向后兼容旧档案），导出/导入一并带走 tab 显隐配置，恢复时同样过滤失效 raw。

已知可接受行为（未改）：快捷键挂在 tab 按钮上，隐藏 tab 的 ⌘0~⌘8 随之失效；快捷指令/右键菜单/今天页的深链仍可跳到隐藏 tab（内容显示但导航栏无高亮）。

编译验证：`xcodebuild -scheme CoolRun -configuration Debug build` BUILD SUCCEEDED（本机需 `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`，且 xcodebuild 需**前台带沙箱绕过**运行——后台模式下绕过不生效）。
