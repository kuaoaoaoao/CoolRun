# 剪切板快捷粘贴功能（⌃⌘1~9）实现计划

## 总体设计
新增一个全局快捷键控制器，按下 ⌃⌘+数字 N 时：取剪切板历史中第 N 条（与界面显示顺序一致：置顶在前、其余按时间倒序，即 1 = 最近复制的内容）→ 写入系统剪切板 → 模拟一次 ⌘V 按键，直接粘贴到当前光标位置。

## 新文件：`CoolRun/ClipboardQuickPasteController.swift`
- 使用 Carbon `RegisterEventHotKey` 注册 9 个快捷键（keyCode 18~25, 29 对应数字 1~9），系统级拦截、可靠且无需第三方库（无沙盒限制）。
- 快捷键固定为 `Control + Command + 数字`，开关存 UserDefaults（key `clipboard_quick_paste_enabled`，默认开启），与现有 `clipboard_history_monitoring_enabled` 模式一致。
- 触发时：
  1. 用 `AXIsProcessTrusted()` 检查辅助功能权限（模拟按键需要）。无权限时不执行，并在首次触发时弹一次系统设置引导（复用/参考 `MenuBarBarItemController` 中已有的辅助功能权限提示模式）。
  2. 调 `ClipboardHistoryStore.shared` 按索引取条目并 `copyToPasteboard(id:)`（该方法已同步 lastChangeCount，不会导致历史被自己重新采集）。
  3. 延迟约 50ms 后用 `CGEvent(keyboardEventSource:virtualKey:keyDown:)` 模拟按下并松起 ⌘V（keycode 9），post 到 `cgSessionEventTap`。
  4. 索引越界（如历史只有 3 条却按了 ⌃⌘5）则静默忽略。

## 接入 `MacAppDelegate.swift`
- `applicationDidFinishLaunching` 中（`ClipboardHistoryStore.shared.startMonitoring()` 之后）创建并启动 controller；`applicationWillTerminate` 中注销快捷键。
- 监听开关变化（UserDefaults observe），动态注册/注销。

## 设置界面 `SettingsView.swift`
- 新增一个"剪切板快捷粘贴"卡片：
  - 开关行（启用/禁用快捷键）。
  - 说明文字：⌃⌘1 = 最近复制，⌃⌘2 = 倒数第二条，依此类推。
  - 辅助功能权限状态行：未授权时显示"去授权"按钮，跳转系统设置辅助功能面板。

## Xcode 工程
- 确认 `CoolRun/` 目录是否为 fileSystemSynchronized group（Xcode 16），是则新文件自动纳入；否则手动在 `project.pbxproj` 中登记。

## 验证
- 编译项目（`xcodebuild`），检查无编译错误。
- 行为说明（需真机手动验证）：复制几段文字后在他处按 ⌃⌘1 应直接粘贴最近一条；置顶条目排在快捷键序列最前。
